# Uygulama ekran görüntüleri

Bu klasöre aşağıdaki isimlerle **1290×2796 piksel, koyu temada çekilmiş PNG** dosyaları koy.
Dosya eklendiğinde site bir sonraki derlemede yer tutucunun yerine gerçek görüntüyü
(AVIF + WebP, 1x/2x/3x) otomatik yerleştirir. Başka bir şey yapman gerekmez.

| Dosya | İçerik |
|---|---|
| `bugun.png` | Bugün (Günün Odağı) ekranı |
| `konular.png` | Konular sekmesi |
| `calisma-sayac.png` | Çalışma sayacı (Pomodoro) |
| `optik-cozum.png` | Optik Çözüm: işaretleme ekranı |
| `optik-rapor.png` | Optik Çözüm: analiz raporu |
| `deneme-analiz.png` | Denemeler: analiz panosu |
| `yapamadiklarim.png` | Yapamadıklarım |
| `hedef-net.png` | Hedef&Net: üniversite/bölüm arama |
| `net-sihirbazi.png` | Net Sihirbazı |
| `planlar.png` | Planlar |
| `sosyal-merkez.png` | Sosyal merkez |
| `duello.png` | Düello |
| `siralamalar.png` | Sıralamalar |
| `basarimlar.png` | Başarımlar (film adlı başarım isimleri görünmeyecek şekilde) |
| `widget-android.png` | Android ana ekran widget'ı |

Çekerken dikkat:
- Örnek veri kullan; gerçek kullanıcı adı, profil fotoğrafı ya da mesaj görünmesin.
- Başarım isimleri film adlarından geliyor; bu isimler ve film görselleri görünmesin.
- Durum çubuğunu temizle (tam şarj, sinyal, saat 09:41 gibi).
